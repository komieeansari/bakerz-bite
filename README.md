# Bakerz Bite — Premium SPA eProject

## Concept
A responsive, single-page bakery & café website inspired by the broad visual language of modern Pakistani bakery shopping sites. It is an original Bakerz Bite design and does not copy the reference site's branding or content.

## Main requirements implemented
- Large rotating offer carousel at the top
- Thick, pill-style category navigation bar
- Home, Cakes, Pastries, Cookies, Pies, Beverages, Desserts & Truffles, Merchandise, Gallery, About Us, FAQ and Contact Us
- A large category banner for EVERY product category, with Bakerz Bite "BB" logo treatment
- Product catalogue driven from `products` JSON-style data inside `script.js`
- Product pop-up with image, description, price and ingredients/specification
- Add-to-basket demo drawer
- Category navigation and smooth scrolling
- Product hover animations
- Offers/deals section
- Gallery lightbox
- Feedback and 1–5 star rating
- FAQ accordion
- About Us / Contact details / Sitemap
- Visitor counter using localStorage
- Continuous bottom ticker with current date/time and HTML5 geolocation attempt
- Responsive mobile, tablet and desktop layouts
- Bootstrap, jQuery, HTML5, CSS3 and JavaScript

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Internet access is recommended because Bootstrap, jQuery, Google Fonts and the demo product images are loaded from CDNs/remote image URLs.
4. For geolocation, use a local server (for example VS Code Live Server) because browsers normally restrict geolocation on ordinary `file://` pages.
